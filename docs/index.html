Bağlantı yok

Bilgisayar kapalıyken buradan çalıştır. Token sadece bu telefonda / bilgisayarda saklanır.

İlk kurulum (bir kez)

GitHub’dan kısa bir “anahtar” alıp buraya yapıştırıyorsun. Sonra butonlarla uzaktan yönetirsin.

1
GitHub’a gir

Telefonunda veya bilgisayarında GitHub hesabınla oturum aç.

2
Token oluştur

Sağ üstteki profil fotoğrafına dokun → Settings → sol alttaki Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

  • Token adı: Atelier panel (istediğin isim)
  • Repository access: Only select repositories → shorts-oto
  • Permissions → Repository:
    • Actions: Read and write
    • Contents: Read and write (saat atlamak için)
  • Generate token → çıkan yazıyı kopyala (bir daha gösterilmez)
3
Buraya yapıştır ve kaydet

Aşağıdaki kutuya yapıştır. Kaydet’e bas. Sonra “Bağlantıyı dene”.

Token’ı kimseyle paylaşma. Sadece bu telefonda / bilgisayarda saklanır; siteye veya repoya yüklenmez.

Token istemiyorsan

GitHub’da elle de çalıştırabilirsin — 3 dokunuş.

  1. Aşağıdaki butona bas → Actions sayfası açılır
  2. Sağda Run workflow’a dokun
  3. Action menüsünden seç (ör. run_now) → yeşil Run workflow
