# Cinematic Shorts SFX (hook / twist / payoff)

- `hook.mp3` — whoosh on claim open
- `twist.mp3` — soft impact / riser mid-story
- `payoff.mp3` — punch on final beat

Generated once via ElevenLabs Sound Generation when `ELEVENLABS_API_KEY` is set,
then reused from this folder (no per-video SFX bill). Local FFmpeg synthetics ship
as fallback so assemble works without a key.

Toggle: `audio.sfx_enabled` / `audio.sfx.enabled` in config.yaml
